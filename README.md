# Luna Edgerunner

Tema oscuro para la app de escritorio y móvil de Claude, inspirado en una noche en la luna: espacio negro con estrellas que parpadean despacio, la Tierra asomando por el horizonte con su halo azul y suelo lunar en primer plano. Acento amarillo neón para botones, enlaces y títulos, y detalles lavanda y azul en las herramientas.

Paleta: `#04040F` fondo · `#0D1424` / `#16213A` superficies · `#F2EDE0` texto · `#FCF427` acento · `#4FA3D1` halo · `#E1E7FF` lavanda · `#E0444F` errores.

## Instalar

En una sesión de terminal:

```
/plugin install luna-edgerunner --marketplace AitorenseForense/edgerunner-theme-claude
```

Desde una shell:

```
claude plugin install luna-edgerunner --marketplace AitorenseForense/edgerunner-theme-claude
```

En la app de escritorio: + junto a la caja de mensajes → Plugins → Add marketplace con `AitorenseForense/edgerunner-theme-claude` → Add plugin.

## Quitar

`claude plugin uninstall luna-edgerunner`, o desactívalo desde Plugins. La app vuelve a su tema por defecto.
